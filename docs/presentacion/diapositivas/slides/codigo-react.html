// src/hooks/useExpressionEvaluator.ts

function evaluatorReducer(state, action) {

  switch (action.type) {

    case 'BUILD': // botón Generar Árbol

      return build(state, state.input);

    case 'EVALUATE': // botón Evaluar

      return { ...state,

        trace: evaluatePostorder(state.tree),

        stepIndex: -1, isPlaying: true };

    case 'STEP_FORWARD': // Siguiente Paso

      return { ...state,

        stepIndex: state.stepIndex + 1 };

  }

}

// el botón: dispatch({ type: 'EVALUATE' })

Ahora la pregunta es: si la lógica no sabe nada de la pantalla, ¿cómo llegan los resultados a la pantalla? Aquí entra React. React es una biblioteca de JavaScript para construir pantallas. La idea principal de React es que la pantalla es el reflejo de unos datos, a los que se les llama estado. Yo no le digo a React «pinta este cuadro verde»; le digo «el paso actual es el 3», y React se encarga de dibujar la pantalla que corresponde al paso 3. Sigamos lo que pasa al oprimir Evaluar, en el diagrama de la izquierda. El botón no calcula nada: solo manda un aviso, que en React se llama dispatch, con el nombre de la acción, EVALUATE. Ese aviso llega al hook, y el hook tiene una función llamada reducer, que es la de la derecha. Un reducer es como un menú: según el nombre de la acción, decide cómo cambia el estado. Si la acción es BUILD, que viene del botón Generar Árbol, llama a build, que a su vez llama al Lexer y al Parser. Si es EVALUATE, llama a evaluatePostorder con el árbol, guarda la lista de pasos en trace, pone el paso actual en menos uno, que significa «todavía no empieza», y activa la reproducción automática. Si es STEP_FORWARD, del botón Siguiente Paso, solo suma uno al paso actual. En cuanto el estado cambia, React vuelve a dibujar la pantalla con los datos nuevos: el nodo activo se pinta de verde, la pila muestra el contenido de ese paso, y el Modo Tutor muestra la frase de ese paso. Por eso digo que la pantalla solo dibuja. El único lugar que llama a la lógica es este reducer, y lo hace en dos momentos: al generar el árbol y al evaluar. Todo lo demás, avanzar, retroceder, cambiar la velocidad, solo cambia el número del paso que se está mostrando.
