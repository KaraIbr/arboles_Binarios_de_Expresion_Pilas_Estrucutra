PROYECTO INTEGRADOR · PARCIAL 02

Árboles Binarios de Expresión y Pilas

Karina Patricia Ibarra Morales

Ingeniería en Desarrollo de Software y Seguridad Informática

Estructuras de Datos y Compiladores · Dra. Blanca Guadalupe Estrada Rentería · Global University

Buenos días, Dra. Estrada. Les voy a presentar mi proyecto integrador, que trata de algo que parece muy sencillo: que la computadora resuelva una operación como (18 − 6) ÷ (2 + 1). Lo que lo vuelve interesante es la condición que nos pusieron: no se vale usar eval(), que es la función de JavaScript que resuelve un texto como si fuera código. Sin eval(), la computadora no sabe qué significa ese texto, así que tuve que enseñarle paso a paso. Y para eso usé justo lo que vimos en la Unidad 5: un árbol binario, sus recorridos y una pila. La presentación sigue el mismo camino que recorre la expresión dentro del programa. Primero les muestro cómo se separa el texto en piezas, luego cómo se arma el árbol, después cómo se recorre y, al final, cómo se calcula con la pila. Luego les enseño cómo está organizado el código por dentro, y terminamos con la aplicación funcionando.
